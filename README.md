# LoL 실전 퀴즈

https://jeongdoheun-source.github.io/lol-quiz/

정적 웹사이트입니다. 서버, 빌드, AI API를 쓰지 않습니다.
**모든 수치는 실행할 때 Data Dragon과 CommunityDragon JSON에서 읽습니다.** 코드에는 게임 수치를 하나도 적어 두지 않았습니다.

## 파일
| 파일 | 역할 |
|---|---|
| `js/core.js` | 데이터 로드, 두 소스 병합, 패치 변경 감지, 자동 갱신 |
| `js/questions.js` | 문제 생성기 55종 (난이도 4단계 × 분야 7개) |
| `js/app.js` | 화면 |

## 난이도
| 단계 | 대상 | 예시 |
|---|---|---|
| 입문 | 아이언~실버 | 소환사 주문 쿨타임, 기본 아이템 가격, 룬 빌드 분류, 사거리 구간 |
| 중급 | 골드~에메랄드 | 사거리·이속 맞대결, 궁극기 쿨타임, 하위·상위 아이템, 핵심 룬 |
| 상급 | 다이아~마스터 | 레벨 N 스탯 계산, 스킬별 쿨타임·마나·사거리, 조합 비용, 같은 줄 룬, 스펠 타이밍 |
| 최상급 | 그랜드마스터~챌린저 | 레벨 역전(성장치), 유효 체력, 방어력 피해 감소율, 스킬 가속 쿨타임, 10분간 궁 횟수, 아이템 골드 효율, 룬 조합 규칙 |

코드에 있는 것은 공식뿐입니다(레벨 성장, 스킬 가속, 방어력 피해 감소). 계산에 쓰는 수치는 모두 JSON에서 가져오고, 해설에 계산 과정과 공식을 함께 보여 줍니다.
골드 효율은 기본 아이템(롱소드 등)으로 능력치 1당 가격을 구하고, 고유 효과가 없는 아이템으로 나머지 능력치 가치를 역산해서 계산합니다.

## 데이터 소스와 상호 보강
- **챔피언:** DD `champion.json`, `champion/{id}.json` ↔ CD `champion-summary.json`, `champions/{key}.json`
- **아이템:** DD `item.json` ↔ CD `items.json` (이름·가격·하위/상위·설명 중 빈 항목을 서로 채움)
- **소환사 주문:** DD `summoner.json` ↔ CD `summoner-spells.json`
- **룬:** DD `runesReforged.json` ↔ CD `perks.json`, `perkstyles.json`
- 어느 소스에서 채웠는지는 설정 화면과 문제 해설의 출처 배지에서 볼 수 있습니다.

## 자동 갱신
1. 문제는 저장하지 않고, 매번 지금 데이터로 즉석에서 만듭니다.
2. 5분~3시간 간격(기본 30분)으로 `versions.json`과 CD `content-metadata.json`을 확인합니다. 탭으로 돌아오거나 네트워크가 다시 연결되면 즉시 확인합니다.
3. 새 버전이 나오면 챔피언 스탯, 스킬 쿨타임·마나·이름, 아이템 가격·능력치, 소환사 주문 쿨타임을 이전 기록과 비교합니다.
4. 풀고 있던 문제가 쓴 값이 바뀌었으면 그 문제를 즉시 새 문제로 바꿉니다.
5. 바뀐 항목으로 "패치 변경" 문제를 자동으로 만듭니다.
